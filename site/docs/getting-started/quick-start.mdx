## A draggable and a droppable

Wrap the element you already render. `Draggable` and `Droppable` render nothing of their own: they
add their behaviour, attributes and ref to the one element they wrap (in Vue, their default slot's
single child).

<Framework name="react">

```tsx title="hello.tsx"
import { Draggable } from "@fragiola/dnd-react/draggable";
import { Droppable } from "@fragiola/dnd-react/droppable";
import { useState } from "react";

export function Hello() {
    const [inBox, setInBox] = useState(false);
    const card = (
        <Draggable id="card" type="card">
            <article aria-label="Card" className="card">
                Drag me
            </article>
        </Draggable>
    );
    return (
        <>
            <Tray>{inBox ? null : card}</Tray>
            <Box>
                <Droppable id="box" accepts={["card"]} onDrop={() => setInBox(true)}>
                    <section aria-label="Box" className="box">
                        {inBox ? card : "Drop here"}
                    </section>
                </Droppable>
            </Box>
        </>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="hello.vue"
<script setup lang="ts">
import { Draggable } from "@fragiola/dnd-vue/draggable";
import { Droppable } from "@fragiola/dnd-vue/droppable";
import { ref } from "vue";

const inBox = ref(false);
</script>

<template>
    <Tray>
        <Draggable v-if="!inBox" id="card" type="card">
            <article aria-label="Card" class="card">Drag me</article>
        </Draggable>
    </Tray>
    <Box>
        <Droppable id="box" :accepts="['card']" @drop="inBox = true">
            <section aria-label="Box" class="box">
                <Draggable v-if="inBox" id="card" type="card">
                    <article aria-label="Card" class="card">Drag me</article>
                </Draggable>
                <template v-else>Drop here</template>
            </section>
        </Droppable>
    </Box>
</template>
```

Callbacks are props written as listeners (`@drop`, `@drag-start`), and the default slot can read
the part's state: `<Draggable id="card" v-slot="{ state }">`.

</Framework>

<Framework name="angular">

```ts title="hello.ts"
import { Component, signal } from "@angular/core";
import { DndDraggable } from "@fragiola/dnd-angular/draggable";
import { DndDroppable } from "@fragiola/dnd-angular/droppable";

@Component({
    selector: "app-hello",
    imports: [DndDraggable, DndDroppable],
    template: `
        <app-tray>
            @if (!inBox()) {
                <article dndDraggable="card" type="card" aria-label="Card" class="card">Drag me</article>
            }
        </app-tray>
        <app-box>
            <section dndDroppable="box" [accepts]="['card']" (drop)="inBox.set(true)" aria-label="Box" class="box">
                @if (inBox()) {
                    <article dndDraggable="card" type="card" aria-label="Card" class="card">Drag me</article>
                } @else {
                    Drop here
                }
            </section>
        </app-box>
    `,
})
export class Hello {
    readonly inBox = signal(false);
}
```

The directives sit on your own elements and add none: the main input is the id, the options are
inputs and the callbacks are outputs (`(drop)`, `(dragStart)`). `exportAs` gives the part's state:
`<article dndDraggable="card" #card="dndDraggable" [class.lifted]="card.state().dragging">`.

</Framework>

There is no provider: the tray and the box can be any components, anywhere. The live version:

## Move it in your state

The drop says what was dropped where (`event.operation.source.id`, `event.operation.target.id`);
moving the data is the app's. While the card follows the pointer, the core moves it with the CSS
`translate` property, once per animation frame, without rendering a component. After your `onDrop` and
`onDragEnd` run, it clears `translate`, so the card goes straight to where your state put it.

<Framework name="react">

```tsx title="board.tsx"
<Droppable
    id={column.id}
    onDrop={(event) => setBoard((board) => moveTask(board, String(event.operation.source.id), column.id))}
>
    <section aria-label={column.title}>{/* … */}</section>
</Droppable>
```

</Framework>

<Framework name="vue">

```vue title="board.vue"
<Droppable
    :id="column.id"
    @drop="(event) => (board = moveTask(board, String(event.operation.source.id), column.id))"
>
    <section :aria-label="column.title"><!-- … --></section>
</Droppable>
```

</Framework>

<Framework name="angular">

```ts title="board.ts"
// in the template: <section [dndDroppable]="column.id" (drop)="moved($event, column.id)">…</section>
moved(event: DroppableEvent<"drop">, to: string) {
    this.board.update((board) => moveTask(board, String(event.operation.source.id), to));
}
```

</Framework>

## Style the drag

The state is on your elements as attributes, present or absent:

```css title="board.css"
.card[data-dnd-dragging] {
    box-shadow: 0 12px 28px rgb(0 0 0 / 0.16);
    z-index: 10;
}
.box[data-dnd-active] {
    outline: 2px dashed;
}
.box[data-dnd-over] {
    background: rgb(59 130 246 / 0.12);
}
.box[data-dnd-refused] {
    outline: 2px dashed red;
}
```

Or with Tailwind: `data-dnd-over:bg-blue-50`. See [styling](/docs/guides/styling).

## The keyboard comes with it

Every draggable is a tab stop. Space or Enter grabs it, the arrows move it, Space or Enter drops it
and Escape cancels. The words a screen reader hears are yours: see
[keyboard and accessibility](/docs/concepts/keyboard-and-accessibility).
