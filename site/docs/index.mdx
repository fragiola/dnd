<Features columns={4}>
<Feature title="No HTML of its own">
A wrapper merges its props, ref and handlers into the element it wraps, a plain one or any Fragiola
primitive, and renders nothing else.
</Feature>
<Feature title="No provider">
A draggable in one corner of the tree and a droppable in another find each other through a drag
space kept per document.
</Feature>
<Feature title="Pay for what you import">
Draggable, droppable, sortable and swappable are separate entries: an app ships only the ones it
imports.
</Feature>
<Feature title="Pointer and keyboard">
Mouse, touch and pen through Pointer Events, and a keyboard path that grabs, moves, drops and
cancels with the same events.
</Feature>
</Features>

<Section title="Two wrappers, anywhere in the tree" eyebrow="Quick start">

```tsx title="board.tsx"
import { Draggable } from "@fragiola/dnd-react/draggable";
import { Droppable } from "@fragiola/dnd-react/droppable";

<Draggable id="card" type="task">
    <article className="card">Drag me</article>
</Draggable>;

<Droppable id="done" accepts={["task"]} onDrop={(event) => move(event.operation.source.id)}>
    <section className="column">Done</section>
</Droppable>;
```

Neither wrapper renders an element, and nothing wraps them both. The state arrives on your elements
as `data-dnd-*` attributes.
</Section>

<Section title="Sort and swap, with your state" eyebrow="Sortable and swappable">

```tsx title="list.tsx"
import { arrayMove, Sortable } from "@fragiola/dnd-react/sortable";

{tasks.map((id, index) => (
    <Sortable key={id} id={id} index={index} group="tasks" onSortEnd={(event) => setTasks((now) => arrayMove(now, event.from.index, event.to.index))}>
        <li>{id}</li>
    </Sortable>
))}
```

No list wrapper: items of one group find each other. While an item is dragged, the core shifts
its neighbours by their `translate`, without a DOM move or a React render; on the drop your state
applies the move with a pure helper. Lists, rows, grids, kanban columns that accept each other,
and swaps within and across groups.
